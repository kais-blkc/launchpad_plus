# Launchpad+

[English version](README.md)

Нативная замена системного меню приложений macOS. Открывается на весь экран с размытым фоном и позволяет искать, фильтровать и сортировать приложения так, как удобно вам: по источнику установки (Homebrew, App Store, DMG вручную, система), по цвету иконки, а также по имени, дате установки, частоте использования, последнему запуску и размеру.

Живёт в меню-баре без иконки в Dock, написано на Swift/SwiftUI, интерфейс на 11 языках.

## Возможности

- **Открывается как привычно**: щипок четырьмя или пятью пальцами на трекпаде, либо <kbd>⌥</kbd><kbd>Space</kbd>, либо иконка в меню-баре.
- **Фильтр по источнику**: App Store, Homebrew (Cask), DMG / вручную, Система, со счётчиками.
- **Фильтр по цвету иконки**: десять цветовых групп, определяются по иконке каждого приложения.
- **Сортировка** по имени, дате установки, частоте использования, последнему запуску, источнику и размеру. Под иконкой показано значение, по которому сортируем. Есть кнопка обратного порядка.
- **Поиск** по мере ввода: первое совпадение сразу выделено, <kbd>Enter</kbd> запускает его.
- **Клавиатура**: стрелки двигают выделение, <kbd>Enter</kbd> запускает, <kbd>Esc</kbd> закрывает.
- **Контекстное меню** (правый клик): Открыть, Показать в Finder, Скопировать путь, Переместить в Корзину.
- **Размер иконок** настраивается, плавные анимации и hover-эффекты.
- **Настройки** (шестерёнка в правом верхнем углу и иконка в меню-баре): язык, автозапуск, выход.
- **11 языков** с переключением на лету: English, 简体中文, Español, Français, Deutsch, 日本語, Português (Brasil), Русский, 한국어, Italiano, Türkçe.

## Требования

- macOS 14 или новее, Apple Silicon
- Command Line Tools (сам Xcode **не нужен**): `xcode-select --install`

## Скачать

1. Скачайте последний `Launchpad-Plus-<версия>.dmg` на странице [Releases](https://github.com/kais-blkc/launchpad_plus/releases).
2. Откройте DMG и перетащите **Launchpad+** в папку **Программы** (Applications).
3. Запустите Launchpad+ из «Программ» (если macOS не даёт открыть, смотрите ниже).

### Как открыть неподписанное приложение

Релизные сборки не подписаны платным сертификатом Apple Developer ID и не прошли нотаризацию, поэтому Gatekeeper блокирует первый запуск скачанной копии сообщением вроде *«Apple не удалось проверить, что Launchpad+ не содержит вредоносного ПО»*. Это ожидаемо. Сделайте один раз любое из двух:

- **Системные настройки:** откройте *Конфиденциальность и безопасность*, прокрутите вниз до сообщения о Launchpad+ и нажмите **Всё равно открыть**, затем подтвердите.
- **Терминал:** снимите флаг карантина и откройте приложение как обычно:
  ```sh
  xattr -dr com.apple.quarantine /Applications/Launchpad+.app
  ```

Если не хотите доверять готовой сборке, соберите её сами (см. [Установка](#установка)): копию, собранную на вашем Mac, система не блокирует. Скачанный файл можно проверить по `.sha256`, приложенному к каждому релизу: `shasum -a 256 -c Launchpad-Plus-<версия>.dmg.sha256`.

## Установка

```sh
git clone https://github.com/kais-blkc/launchpad_plus.git launchpad-plus
cd launchpad-plus
make install
```

`make install` собирает приложение, копирует его в `/Applications/Launchpad+.app` и запускает. В меню-баре появится значок сетки.

Остальные команды:

| Команда | Что делает |
|---|---|
| `make` / `make run` | Останавливает запущенную копию, пересобирает и запускает из `build/` |
| `make build` | Только собирает `build/Launchpad+.app` |
| `make stop` | Завершает приложение |
| `make install` | Собирает и устанавливает в `/Applications` |
| `make dmg` | Собирает релизный DMG в `build/` |

Чтобы приложение запускалось само, откройте иконку в меню-баре (или шестерёнку в окне) и включите **Запускать при входе**. Делайте это из копии, установленной в `/Applications`.

### Первый запуск

- Приложение подписано локально (ad-hoc) и собрано на вашем компьютере, поэтому Gatekeeper его не блокирует.
- Для жеста на трекпаде macOS может запросить разрешение **Мониторинг ввода**. Если жест не срабатывает, разрешите его в *Системные настройки → Конфиденциальность и безопасность → Мониторинг ввода* и перезапустите приложение.
- Системный жест «Приложения» можно не отключать: окно Launchpad+ открывается поверх него. Но если выключить его в *Системные настройки → Трекпад → Дополнительные жесты*, окна не будут дублироваться.

## Как пользоваться

| Действие | Как |
|---|---|
| Открыть | Щипок большим и тремя пальцами, либо <kbd>⌥</kbd><kbd>Space</kbd>, либо иконка в меню-баре → *Показать приложения* |
| Закрыть | <kbd>Esc</kbd>, развести пальцы, клик по пустому месту или переключение в другое приложение |
| Поиск | Просто начните печатать |
| Двигать выделение | Стрелки |
| Запустить | Клик по приложению или <kbd>Enter</kbd> на выделенном |
| Фильтр по источнику | Сегменты *Источник* сверху |
| Фильтр по цвету | Клик по цветному кружку, повторный клик снимает |
| Сбросить фильтры | Кнопка *Сбросить фильтры* под панелью появляется при активном фильтре |
| Сортировка | Выпадающий список *Сортировка*, стрелка рядом меняет порядок |
| Размер иконок | Ползунок справа в панели |
| Действия с приложением | Правый клик по приложению |
| Язык, автозапуск, выход | Шестерёнка в правом верхнем углу или иконка в меню-баре |

### Как определяется источник

| Источник | Правило |
|---|---|
| App Store | внутри бандла есть `Contents/_MASReceipt/receipt` |
| Brew | приложение найдено в `Caskroom` (`/opt/homebrew/Caskroom`, `/usr/local/Caskroom`) |
| Система | лежит в `/System/` или бандл `com.apple.*` без чека App Store |
| DMG | всё остальное (из DMG, архива или скачано с сайта) |

## Удаление

1. Выключите **Запускать при входе** и выберите **Выйти** в меню иконки.
2. Удалите `/Applications/Launchpad+.app`.
3. По желанию: `defaults delete dev.launchpadplus.app` сотрёт сохранённые настройки (язык, размер иконок).

## Настройка под себя

- **Хоткей**: код клавиши и модификаторы в `Sources/LaunchpadPlus/AppDelegate.swift` (`hotKey.register`).
- **Чувствительность жеста**: `pinchInRatio` / `pinchOutRatio` в `Sources/LaunchpadPlus/TrackpadGesture.swift`.
- **Иконка приложения**: замените `Resources/AppIcon-source.png` (PNG 1024×1024) и запустите `make`. Форма иконки macOS накладывается автоматически.
- **Переводы**: `Resources/<язык>.lproj/Localizable.strings`. После правок запустите `scripts/check_strings.py`, чтобы убедиться, что во всех языках одинаковый набор ключей.

## Ограничения

- Жест на трекпаде использует приватный фреймворк Apple `MultitouchSupport`. После обновления macOS он может перестать работать, хоткей при этом продолжит работать.
- Последний запуск и счётчик запусков берутся из метаданных Spotlight, а macOS хранит их не для всех приложений.
- Приложение работает без sandbox и не может быть опубликовано в Mac App Store.
- Языки с письмом справа налево пока не поддерживаются.

## Структура проекта

```
Sources/LaunchpadPlus/   код приложения (SwiftUI + AppKit)
Resources/               Info.plist, исходник иконки, переводы (*.lproj)
scripts/                 build.sh, make_icon.swift, check_strings.py
Makefile                 run / build / stop / install / dmg
```

## Выпуск релиза (для разработчика)

Версия хранится в файле `VERSION`. Пуш тега запускает сборку DMG на GitHub Actions и публикует релиз:

```sh
echo "0.2.0" > VERSION && git commit -am "Bump version to 0.2.0"
git tag v0.2.0 && git push origin main v0.2.0
```

`make dmg` собирает `build/Launchpad-Plus-<версия>.dmg` локально.
